# 잿불의 회랑 (Ashfall)

핵앤슬래시 로그라이크. 한 판 **10~20분**, 매 판 다른 빌드.
빌드 도구 없이 브라우저에서 바로 돌아가는 순수 ES 모듈 + Canvas 2D 프로젝트다.

```
cd games/ashfall
node tools/serve.mjs        # http://localhost:8123
```

---

## 1. 무엇을 만들었는가

**Core Loop**

```
무기 선택 → 방 진입 → 전투(이동/대시/콤보/특수기)
   → 전멸 → 문 3개 중 선택(보상·위험을 미리 보고 결정)
   → 권능 획득(빌드 성장) → 다음 방 …
   → 구역 보스 → 다음 구역 → 최종 보스 → 승리/사망
   → 잿가루로 영구 강화 → 다음 런
```

- 구역 3개 × (전투 4방 + 보스 1방) = **15방**
- 봇 기준 순수 전투 시간 3~6분, 실제 플레이(선택/읽기 포함) **12~18분**

**조작** — 이동 `WASD` · 조준 `마우스` · 공격 `좌클릭`/`J` · 특수기 `우클릭`/`K` · 대시 `Space` · 일시정지 `Esc`

## 2. 재미의 축

### 무기 3종 — 리듬이 서로 다르다
| 무기 | 콤보 | 정체성 | 특수기 |
|---|---|---|---|
| 잿불검 | 3연격 | 균형형, 3타에 큰 넉백 | 잿불 관통 — 무적 돌진 참격 |
| 파쇄추 | 2연격(느림) | 슈퍼아머(휘두르는 동안 피해 30%↓, 넉백 저항) | 대지 붕괴 — 도약 후 광역 충격파 |
| 쌍아검 | 4연타(빠름) | 대시로 후딜 캔슬, 대시 직후 첫 타 ×1.75 | 피의 회전 — 이동하며 지속 광역 |

### 권능(Boon) — 빌드가 갈리는 지점
- 4명의 신(재/서리/폭풍/피) × 슬롯(**기본공격·대시·특수기·패시브**)
- **기본공격/대시/특수기 슬롯은 1개만 장착** → 초반 선택이 런 전체의 방향을 정한다
- 같은 권능을 다시 얻거나 강화 보상을 받으면 레벨업(최대 3)
- 희귀도 4단계가 수치를 스케일(일반 1.0 → 전설 2.3)
- **합일 권능(Duo)** 6종 — 두 신의 권능을 모두 가질 때만 등장
  예) 열충격(화상+빙결 동시 → 폭발), 초전도(빙결 대상 타격 → 강화 연쇄 번개),
  재의 갈증(화상 피해의 35% 흡혈), 혈류 과부하(출혈 대상 타격 → 다중 방전)

### 선택에 실제 차이가 있다
- **문**: 보상 종류가 문 위에 아이콘으로 미리 보인다 (권능 / 강화 / 회복 / 최대체력 / 무기각인 / 골드 / 상점)
- **엘리트 문**: 저주 3개 중 하나를 짊어지면(런 전체 적용) 보상 희귀도가 올라간다 — 명시적 Risk↔Reward
- **위치 잡기**: 무쇠 방벽은 정면 피해를 82% 막는다 → 돌아서 등을 쳐야 한다
- **공수 전환**: 모든 적 공격은 **예고 → 판정** 구조. 읽고 대시(무적)로 빠져나갈 수 있다

### 세계가 반응한다
- 히트스톱 · 화면 흔들림 · 피격 플래시 · 피해 숫자 · 파티클 · 대시 잔상 · 충격파 링 · 연쇄 번개
- WebAudio 절차적 효과음 20여 종(에셋 없이 합성) — 나중에 샘플로 교체 가능한 구조
- 카메라: 조준 방향 룩어헤드 + 아레나 커버 줌 + 흔들림
- 저체력 화면 비네트, 보스 페이즈 전환 연출, 상태이상 오라

### 상태이상이 서로 맞물린다
| 상태 | 효과 |
|---|---|
| 화상 | 중첩 도트 |
| 냉기 | 둔화, 최대 중첩 시 **빙결** |
| 빙결 | 행동 불가 + **받는 피해 ×1.35** (권능 없이도 기본 보상) |
| 감전 | 연쇄 번개/피해 증폭의 연결점 |
| 출혈 | 중첩 도트, 냉기·폭풍 권능과 상호작용 |

플레이어도 디버프를 받는다 — 서리창 기병의 돌진은 **냉기(이동 둔화)**, 폭풍 감시자의 탄은 **감전(집중 회복 감소)**.

### 보스 3종
페이즈별로 패턴 풀·속도·쿨다운이 바뀐다. 몸통 접촉은 피해를 주지 않고 밀어낸다 —
**근접해서 때리는 것을 처벌하지 않고, 피해는 전부 예고된 패턴에서만 나온다.**

### 메타 진행
사망/클리어 시 **잿가루**를 얻어 영구 강화 7종(체력·피해·이동·방 회복·행운·대시 충전·부활)을 산다.
세이브는 버전 + 마이그레이션 + 손상 복구를 갖춘다.

## 3. 구조

```
src/
  core/     math rng events input save        ← 엔진 비의존 유틸
  data/     balance weapons enemies boons     ← 모든 수치 (튜닝 지점)
  sim/      world player enemyAI boss combat loadout run
  render/   camera renderer vfx hud
  audio/    sfx
  ui/       screens (DOM 오버레이)
  main.js   부트스트랩 + 고정 타임스텝 루프
```

**규칙**

1. `sim/` 은 DOM·캔버스·오디오를 전혀 모른다. 그래서 node 에서 런 전체를 돌릴 수 있다.
2. sim 은 **무슨 일이 일어났는지**만 `EventBus` 로 알린다. 어떻게 보이고 들릴지는 `render/`·`audio/` 가 정한다.
3. 권능은 `loadout` 으로 **컴파일**된다 — 보유 목록 → 스탯 + 훅 배열. 전투 루프는 훅만 호출한다.
4. UI 버튼은 게임 규칙을 갖지 않는다. `ui/screens.js` 는 `main.js` 의 컨트롤러만 호출한다.
5. 시뮬레이션은 시드 RNG로 결정론적이다(같은 시드 = 같은 런).

**책임 분리 요약**

```
입력 → intent → sim.step() → 상태 변화 + 이벤트
                                  ├→ vfx    (파티클/숫자/링)
                                  ├→ sfx    (WebAudio)
                                  ├→ hud    (상태 표시)
                                  └→ screens(선택 UI)
```

## 4. 밸런스 튜닝

수치는 전부 `src/data/` 에 있다. 코드를 고칠 필요가 없다.

| 파일 | 내용 |
|---|---|
| `balance.js` | 플레이어 스탯, 히트스톱/셰이크, 상태이상, 런 구조, 보상 가중치, 저주, 희귀도, 상점, 메타 강화 |
| `weapons.js` | 무기별 콤보 프레임(선딜/판정/후딜), 피해, 사거리, 각도, 넉백, 특수기 |
| `enemies.js` | 적 스탯·AI·예고 시간, 보스 페이즈/패턴, 구역별 적 풀과 스폰 예산 |
| `boons.js` | 권능 정의(수치 + 적용 함수), 합일 권능 조건 |

바꾼 뒤에는 반드시:

```
node tests/run-all.mjs      # 단위 + 헤드리스 런 + 밸런스 스윕
```

`sweep.mjs` 는 봇으로 무기 × 시드를 돌려 **승률 / 평균 도달 방 / 사망 지점**을 뽑는다.
봇은 사람보다 못 하므로 봇 승률 10~25%가 대략 "사람에게 적당히 어려운" 지점이다.

## 5. 테스트

```
node tests/run-all.mjs      # 단위 28 + 헤드리스 플레이 + 밸런스 스윕
node tests/browser.mjs      # 실제 브라우저 스모크 19항목 (playwright-core 필요)
```

- `unit.mjs` — RNG 결정론, 판정 수학, 데이터 무결성(모든 권능/보스 패턴 참조 검증),
  슬롯 배타성, 합일 해금 조건, 상태이상 전이, 방패 방향 판정, 무적, 부활,
  방 클리어→문→보스 진행, 보스 앞 회복, 승리 조건, 저주 적용, 세이브 마이그레이션/손상 복구
- `bot.mjs` — 예고를 읽고 회피하고 문을 의미 있게 고르는 자동 플레이어
- `browser.mjs` — 실제 키보드/마우스 입력으로 타이틀 → 전투 → 일시정지 → 권능 선택 →
  방 클리어 → 문 진입 → 보스전 → 세이브까지 검증하고 스크린샷을 남긴다
