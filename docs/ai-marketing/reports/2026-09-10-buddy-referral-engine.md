# FINAL JUDO AI CMO — Buddy Referral Engine

- 기준일: 2026-09-10
- 상태: 전략 제안 / 외부 실행 미승인
- 내부 회원수·매출·전환율: **데이터 미연결**

## 오늘의 판단

이번 우선순위는 **MEMBER-LED ACQUISITION**, 즉 기존회원과 함께 들어오는 `Buddy / 친구 동반 체험`을 신규획득 채널로 검증하는 것이다. 직전 실행의 출석 이탈 조기경보와 중복하지 않고, 이번에는 기존회원의 실제 관계망을 신규 체험으로 연결하되 무조건적인 할인보다 `동반 체험 → 실방문 → 등록 → 30일 활성`까지 추적하는 추천 퍼널을 설계한다.

## 발견한 변화

- YU Taekwondo는 2026-09-14~20 Buddy Week를 운영하며 기존회원이 친구·동료·가족을 자신의 정규수업에 동반하도록 하고, 단순 동반이 아니라 **추천자가 실제 신규회원으로 등록된 경우**에만 추천 보상으로 집계한다.
- GIANT Martial Arts는 2026년 8월 Buddy Week를 정규 이벤트 캘린더에 포함하고, 신규회원용 앱·시간표·추천 프로그램 안내를 한 뉴스레터 안에 연결한다.
- QFit Gym은 2026년 추천 프로그램에서 추천된 친구가 첫 달 가입 후 **다음 달 갱신을 완료한 뒤** 기존회원 보상이 발생하도록 설계했다. 파이널유도에 동일 할인율을 적용할 근거는 없지만, 보상을 단순 리드가 아니라 유지 이후에 연결하는 구조는 참고할 가치가 있다.
- ACSM 2026 Fitness Trends에서 `Adult Recreation and Sport Clubs`가 처음 Top 20에 진입했으며, 재미·유연성·사회적 연결을 결합한 운동 참여가 증가하는 흐름을 제시한다. 이를 파이널유도의 전환율 예상치로 사용하지 않는다.
- 네이버 스마트플레이스는 2026-05-28부터 헬스장·필라테스·요가 등 일부 업종의 검색 결과에서 여러 업체 이미지와 방문자 리뷰를 더 풍부하게 노출하는 `범용 특화` 컬렉션을 적용했다. 유도장에 동일 적용되는지는 관리자 화면 확인이 필요하다.
- 당근은 2026-05-29 비즈프로필 관리자 홈을 개편해 방문자 수, 단골 현황, 소식 반응률, 방문 경로·검색어 등을 확인할 수 있도록 했다.

## 즉시 실행 3개

1. **FINAL BUDDY PASS v0.1 설계**: 기존회원 1명 + 초보 친구 1명이 같은 수업의 초보자 구간을 함께 경험하는 구조를 만든다. 실제 수용 가능한 반만 대상으로 하며 시간대별 여석은 `데이터 미연결`이다.
2. **추천 소스 추적 필드 추가**: `referrer_member_id / buddy_lead_id / relation_type / invite_date / reserved / duo_show / paid / active_30d / reward_eligible`를 분리한다. 공개 저장소에는 개인 식별값을 저장하지 않는다.
3. **채널별 콘텐츠 분리**: 네이버는 `친구와 첫 유도 체험 시 무엇을 하나요?` 정보형, 인스타그램은 2인 초보 드릴·낙법·균형 미션형, 당근은 실제 승인된 날짜와 여석이 있을 때만 지역 Buddy Day 소식형으로 운영한다.

## 실험

### EXP-184 Buddy vs Solo Trial
- 가설: 혼자 체험하는 것보다 기존회원과 동반한 체험이 실방문과 초기 적응에 유리할 수 있다.
- KPI: 예약→실방문→등록→30일 활성.
- 성공/중단: 최소 2개 코호트에서 Solo 대비 하단 퍼널 개선이 전혀 없으면 별도 Buddy 운영을 중단하거나 대상군을 축소한다.

### EXP-185 Reward After Retention
- 가설: 추천 즉시 보상보다 추천회원이 일정 기간 실제 활동한 뒤 보상하는 구조가 허수 추천과 비용 누수를 줄일 수 있다.
- KPI: 추천등록→30일 활성→추천비용/활성회원.
- 성공/중단: 보상 유무가 추천량·활성률에 유의미한 운영상 개선을 만들지 못하면 물질 보상 확대를 중단한다.

### EXP-186 Dormant + Buddy Return
- 가설: 휴면회원이 혼자 복귀하기보다 친구·가족과 함께 복귀할 선택지가 있으면 재방문 장벽을 낮출 수 있다.
- KPI: 대상→복귀예약→실방문→30일 활성.
- 성공/중단: 2개 코호트에서 일반 복귀안내 대비 개선이 없으면 해당 분기 중단.

위 기준은 예상 성과가 아니라 실험 판정 규칙이며 현재 비교 기준선은 **데이터 미연결**이다.

## 필요한 대표 승인·입력

- 시간대별 안전정원·실제 여석
- 최근 체험 예약·실방문·등록·30일 활성 데이터
- 신규회원 유입경로에 `회원추천` 구분이 존재하는지 여부
- 기존 추천·친구동반 운영 여부와 실제 비용
- 휴면회원·만료예정자 대상 연락 범위와 개인정보 동의 상태
- 추천 보상을 도입할 경우 가능한 보상 유형·예산·회계 처리 기준

실제 고객 메시지 발송, 친구 연락처 수집, 무료체험 제공, 할인·상품 지급, 네이버·인스타그램·당근 게시, 광고 집행은 대표의 별도 명시적 승인 없이 실행하지 않는다.

## KPI 상태

- 회원추천 신규문의: **데이터 미연결**
- 추천→체험예약: **계산 불가**
- 예약→동반 실방문: **계산 불가**
- Buddy 체험→등록: **계산 불가**
- Buddy 등록→30일 활성: **계산 불가**
- 추천회원 재등록률: **데이터 미연결**
- 추천자의 재등록·만족 변화: **데이터 미연결**
- 휴면+Buddy 복귀율: **데이터 미연결**
- 추천 관련 비용: **데이터 미연결**
- 추천 유입 매출: **데이터 미연결**

핵심 데이터 체인: `member_referrer → buddy_invite → duo_trial → paid → 30d_active → referrer_renewal → referral_revenue`.

## Auditor

추천 프로그램의 핵심 위험은 할인 남발, 허수 추천, 기존 가족·지인의 개인정보 무단 수집, 실제 여석을 무시한 동반체험, 그리고 `친구와 하면 오래 다닌다`를 검증된 파이널유도 효과처럼 표현하는 것이다. 추천 보상은 실제 정책·예산 승인 전에는 제안 상태로만 둔다. Buddy 연락처는 본인 또는 보호자의 적법한 동의 없이 기존회원에게 받아 CRM에 입력하지 않는다.
